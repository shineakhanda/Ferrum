# Ferrum 1.0.0

First public release, for Minecraft **26.3** and **1.21.11** (Fabric).

## Downloads

| File | Minecraft | Java |
|---|---|---|
| `ferrum-1.0.0+26.3.jar` | 26.3 | 25 |
| `ferrum-1.0.0+1.21.11.jar` | 1.21.11 | 21 |

Requires Fabric Loader 0.20.1+ and Fabric API. Android players: use the 1.21.11 file.

## Highlights

- **Block face culling.** Chunk faces pointing away from the camera are no longer sent to the GPU.
- **Occlusion culling** for mobs, items, chests, signs and other block entities hidden behind walls.
- **Render scale with FSR upscaling.** Render the world at a lower resolution and keep it sharp.
- **Render pass optimization.** Fully opaque cutout faces, such as grass, are drawn in the faster solid pass.
- **New Video Settings screen** with a Render page of per-type animation, particle and entity toggles.
- **Hardware presets** that detect Android, GL translation layers and desktop GPUs.
- **Automatic compatibility** with Sodium, Iris, VulkanMod, BadOptimizations and EntityCulling:
  overlapping Ferrum features turn themselves off.

See [CHANGELOG.md](../../CHANGELOG.md) for the full list.

## Known limitations

- Minecraft 26.x does not start on current Android launchers (SDL3 is missing); this is a launcher
  limitation. Use 1.21.11 on Android.
- With Sodium installed, Ferrum's terrain features are off because Sodium replaces the terrain
  renderer. Ferrum's other features still apply.
- Render scale is paused while an Iris shader pack is active.

## Reporting problems

Please open an issue with your `latest.log`, an F3 screenshot and your device details.
